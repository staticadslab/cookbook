


## Knowledge base (LLMWiki)

Durable product/architecture knowledge for this repo lives in the shared LLMWiki repo at
`../llm-wiki` (GitHub: `staticadslab/llm-wiki`).

- Before starting work: pull `../llm-wiki` and read `../llm-wiki/wiki/index.md` plus
  `../llm-wiki/wiki/products/cookbook.md`.
- Work from the GitHub issue and keep it updated (`../llm-wiki/scripts/gh-sal`).
- Write durable knowledge back to the wiki before finishing, following
  `../llm-wiki/schema/AGENTS.md`.
- Do not duplicate issue state into the wiki; link to issues instead.
